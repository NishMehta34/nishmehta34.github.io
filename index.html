Hiring Signals Pipeline

Personal project, 2026

Turns public job boards into a daily, ranked list of companies hiring engineers.

A company hiring three backend engineers is short of engineering capacity, which makes it a likely buyer of outsourced development. Python loads Greenhouse, Lever and Ashby job boards as raw data; dbt models in PostgreSQL work out which roles opened and closed, then score each company from 0 to 100 with a plain-English reason. It runs every morning on GitHub Actions, and data-quality tests stop a bad build from publishing.

Built with Python, dbt, PostgreSQL, SQL, GitHub Actions, Docker

Forecasting Great Britain's electricity demand

MSc dissertation, University of Greenwich, 2026

The most complex model wasn't the most accurate one.

I compared six approaches, from naive baselines to XGBoost, LSTM and a Transformer, on NESO demand data from 2001 to 2025, using the past seven days to forecast the next 24 hours. On unseen 2023 to 2025 data, XGBoost was most accurate overall, and no single model won every year. The project includes automated integrity tests and an interactive Streamlit dashboard.

Built with Python, XGBoost, LSTM, Transformer, Streamlit
